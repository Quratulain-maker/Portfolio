# AI Spell Checker App using NLP

An AI-powered mobile application developed using Flutter and Natural Language Processing (NLP) for spell and grammar correction.

---

## Project Overview

The AI Spell Checker App helps users identify spelling and grammar mistakes instantly using NLP-based text analysis.

The project demonstrates the practical implementation of:
- Artificial Intelligence
- Natural Language Processing
- Flutter Mobile Development
- API Integration

---

## Features

- Real-time spell checking
- Grammar correction
- Smart correction suggestions
- Clean and modern UI
- Copy corrected text
- NLP-powered analysis

---

## Technologies Used

| Technology | Purpose |
|------------|---------|
| Flutter | Mobile App Development |
| Dart | Programming Language |
| LanguageTool API | NLP Spell Checking |
| HTTP Package | API Communication |

---

## How It Works

1. User enters text
2. App sends text to NLP API
3. AI analyzes spelling & grammar
4. Mistakes are detected
5. Suggestions are displayed
6. Corrected text is generated

---

## Connection with NLP

Natural Language Processing (NLP) is a branch of Artificial Intelligence that helps computers understand and process human language.

This project uses NLP for:
- Spell checking
- Grammar analysis
- Sentence correction
- Intelligent suggestions
